# KritaTogether

[en English version](README.md)

Плагин для Krita, реализующий совместное рисование на общем холсте в реальном времени. Несколько пользователей могут одновременно работать над одним документом; слои, пиксельные изменения и параметры фильтров синхронизируются через локальную сеть или промежуточный relay-сервер.

## Возможности

- Синхронизация рисования в реальном времени с задержкой порядка 70 мс.
- Поддержка многослойных документов: создание, удаление и переименование слоёв, управление видимостью, прозрачностью и режимом наложения.
- ~~Синхронизация параметров фильтрующих слоёв (для поддерживаемых типов фильтров).~~ Не стабильно!
- Два режима подключения:
  - Прямое TCP-соединение (при наличии доступных портов).
  - Через relay-сервер (для работы в окружениях за NAT).
- Аутентификация по паролю для ограничения доступа.
- Передача только изменившихся областей холста (dirty rectangles), что снижает сетевую нагрузку.

## Требования

- Krita 5.2 или новее (рекомендуется стабильная версия).
- Интерпретатор Python, встроенный в Krita (установка дополнительных пакетов не требуется).
- Все зависимости входят в стандартную библиотеку Python.

## Установка

1. Скопируйте каталог `krita_together` в папку плагинов Krita:
   - Windows: `%APPDATA%\krita\pykrita\`
   - Linux: `~/.local/share/krita/pykrita/`
   - macOS: `~/Library/Application Support/krita/pykrita/`
2. Перезапустите Krita.
3. Откройте **Настройки → Настроить Krita → Python Plugin Manager** и активируйте плагин **KritaTogether**.
4. Перезапустите Krita повторно.

После активации в меню **Инструменты** появится пункт **Общий доступ...**, а в списке докеров — панель управления плагином.

## Использование

### Прямое подключение

1. Хост: в панели плагина укажите порт (по умолчанию `50007`) и нажмите **Создать сессию**.
2. Клиент: укажите IP-адрес хоста и тот же порт, затем нажмите **Подключиться**.
3. Если задан пароль, он должен совпадать на обеих сторонах.
4. После подключения клиент автоматически создаёт документ с параметрами хоста и запрашивает полную синхронизацию.

### Подключение через relay-сервер

1. Разверните relay-сервер на машине с публичным IP-адресом:
   ```bash
   python3 relay_server.py
2. Откройте один TCP-порт (по умолчанию 50008) в фаерволе.
3. В плагине перейдите на вкладку Через сервер и заполните поля:
 - IP сервера — адрес relay-сервера.
 - Порт — порт relay-сервера.
 - Токен комнаты — произвольная строка длиной не менее 8 символов (рекомендуется случайный токен).
 - Пароль — пароль сессии.
Хост нажимает Создать комнату, клиент — Подключиться к комнате.

Relay-сервер не хранит и не анализирует передаваемые данные, выполняя только пересылку байтов между участниками.
